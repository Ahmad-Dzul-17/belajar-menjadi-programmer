# Profil Mahasiswa — Worksheet PABW Pertemuan 8

Halaman profil pribadi bertema hijau-teal dan cyan, dibangun sebagai latihan JavaScript Modern ES6+, object, array, fungsi murni, dan array methods.

## Cara menjalankan
1. Buka folder `worksheet-p8` di VS Code.
2. Pasang ekstensi **Live Server**.
3. Klik kanan `profil.html` → **Open with Live Server**.
4. Buka DevTools (`F12`) → Console untuk melihat `console.log` dan `console.table`.

Jangan membuka file dengan klik dua kali (`file://`) karena worksheet menggunakan `type="module"`.

## Struktur
- `profil.html`: struktur halaman dan target elemen yang diisi JavaScript.
- `js/app.js`: data profil, array proyek, dua fungsi murni, `map`, `filter`, `find`, dan render data. Kode dibuat ringkas dengan nama deskriptif dan tanpa komentar yang tidak diperlukan.
- `tokens.css`: design tokens warna, tipografi, jarak, radius, dan bayangan.
- `base.css`: reset dan gaya dasar.
- `layout.css`: tata letak responsif.
- `komponen.css`: tabel, tombol, input, tag, dan fokus keyboard.
- `tema.css`: dukungan tema gelap manual dan preferensi sistem.
